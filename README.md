# 寻花令 · 诗词检索

根据已知的字、位置和游戏反馈，查找符合条件的诗词上下句。

**[在线使用](https://veyrid.github.io/XunHuaLingSearch/)** · [下载离线版](https://github.com/Veyrid/XunHuaLingSearch/archive/refs/heads/main.zip)

## 开始使用

1. 选择上下句字数；知道朝代时，可先选择朝代。
2. 填写已知的字和位置，或录入游戏反馈。
3. 点击 **开始检索**。修改条件后，再次点击检索。

也可以点击“填入「明月」示例”体验筛选。离线使用时，下载并解压整个项目，双击根目录的 `index.html`；请保留完整的 `dist` 文件夹。离线版无需安装软件或联网。

## 筛选条件

所有条件同时生效。字数不含标点，上下句的位置分别从 **1** 开始。

| 条件 | 用法与示例 |
| --- | --- |
| 字数 | 五言为上下句各 5 字，七言为各 7 字；也可不限，或分别设置每句 1–40 字。 |
| 朝代 | 可多选，保留任一选中朝代的出处；不选即不限。“明末清初”在明、清两项中都能找到。 |
| 必须包含 | `明月` 表示两字都要出现；`月月` 表示至少出现两次。默认按整副合计，也可分别限定上句、下句。 |
| 不能包含 | `风雨雪` 表示这些字都不能出现；可作用于整副或指定句。 |
| 字与位置确定 | “上句／月／4”表示上句第 4 字为“月”；“下句／处／1,2”表示下句第 1、2 字都是“处”。 |
| 有字但错位 | “上句／月明／1,3”表示两字在整副中存在，但都不能在上句第 1、3 位，允许只出现在下句。 |

定位和错位条件均可添加多条。若错位的字还必须出现在指定句，请同时填写该句的“必须包含”。冲突或未填完整的条件会显示提示。

## 录入游戏反馈

展开“录入一轮寻花令反馈”，输入猜过的上下句并添加。点击每个字，依次切换 **未设置 → 灰色 → 黄色 → 绿色**；上下句全部标完后，这一轮才参与筛选。支持多轮反馈，标完后点击“开始检索”。

字是否存在和重复次数按上下句整体判断，绿色位置按各句判断。默认采用 Wordle 的次数规则：先分配绿色，再按剩余次数分配黄色。同一字同时有彩色和灰色时，灰色可能表示多猜了一次，不能直接把这个字排除。如果游戏只判断字是否存在，可选择“逐字判断”。

## 查看结果

- 结果按朝代大致由早到晚排列，每页 20 副；可用上一页、下一页，或输入页码后点击“跳转”或按回车。
- 上下句文字完全相同的结果合并显示，点击题名可查看全文和各个出处；可一键复制上下句。
- 默认使用简体匹配；遇到繁简或版本用字差异，可切换“原文匹配”。
- 默认“严格配对”依据诗文结构组成上下句。找不到时可试“所有相邻句（宽松）”，但宽松结果可能跨联，应查看全文确认。

## 在线检索为什么比较慢？

在线版需要先下载相关词库，再在浏览器内筛选；离线版直接读取本机文件。不限朝代时，一次五言或七言检索涉及约 200 个数据文件，文件原始大小合计约 **202 MB / 263 MB**，实际传输量取决于压缩和缓存。

已知朝代时，先选朝代可以减少下载量。已有结果后继续增加条件，可在符合复用条件时直接筛选；改变字数、放宽条件或切换匹配模式通常需要重新查库。只增加字或位置条件，不会减少首次检索需要读取的文件。频繁使用时，离线版通常更快。

## 词库与许可

词库包含 **745,625 首可配对作品**，涵盖先秦至清代的诗、词及古乐府。严格模式有 **3,580,312 条**来源记录，宽松模式有 **6,786,179 条**；来源记录会在检索时去重，并非游戏官方题库。古籍版本和分句可能有差异。

诗词数据来自 **chinese-poetry** 和 **Werneror/Poetry**，简繁转换使用 **OpenCC-js**，各自的许可证随项目保留。项目自身未设置开源许可证。查询条件和游戏反馈在浏览器内处理，不提交到应用服务器；在线版会向本站请求静态文件。
