# 维护说明

## 本机预览与检查

网站使用 HTML、CSS 和 JavaScript，`dist` 是完整发布目录。根目录的 `index.html` 用于离线跳转。

以下命令需要 Node.js，Python 测试需要 Python 3.11 或更高版本；无需安装构建依赖。

```sh
node scripts/preview.cjs
node scripts/version-assets.cjs
node --test tests/search.test.cjs tests/pairing.test.cjs tests/catalog.test.cjs tests/ui.test.cjs
python -B tests/prepare-data.test.py
node scripts/check-pages.cjs
node scripts/validate-data.cjs
```

预览地址为 `http://127.0.0.1:5173/`。检查项目子路径时，使用 `node scripts/preview.cjs /XunHuaLingSearch/`。真实词库性能检查可运行 `node scripts/benchmark-search.cjs`。

修改脚本、样式或重建词库后，先运行 `node scripts/version-assets.cjs` 更新入口资源版本，再运行检查，避免浏览器混用新页面和旧缓存。

## 重建词库

`data-sources.lock.json` 固定数据源版本、下载地址及收录范围，`sources/reading-corrections.json` 保存作品整理规则。重建需要 Python 3.11+、Node.js 和 pnpm。

```sh
pnpm install --frozen-lockfile
python scripts/prepare-data.py --download
node scripts/build-data.cjs
node scripts/version-assets.cjs
node scripts/validate-data.cjs
node scripts/check-pages.cjs
```

准备脚本从固定的 GitHub 压缩包读取数据并校验版本，不执行来源仓库中的脚本。已有压缩包时可省略 `--download`。重建后刷新页面；通过检查后可清理 `.cache` 和 `node_modules`，保留 `dist`、`sources` 及版本锁定文件。

## GitHub Pages

仓库在 **Settings → Pages → Source** 中选择 **GitHub Actions**。推送默认分支后，工作流运行测试和词库检查，再发布 `dist`；也可在 Actions 页面手动运行。其他分支和 pull request 只检查。

网站资源使用相对路径，兼容仓库子目录。当前站点约 818 MB；扩库前应运行发布检查，确保不超过 GitHub Pages 的 1 GB 上限。数据和依赖的许可证须随发布目录保留。

测试结果以 [GitHub Actions](https://github.com/Veyrid/XunHuaLingSearch/actions) 为准，用户可见的功能变更记入 [更新记录](../CHANGELOG.md)。
